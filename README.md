# dotfiles

One-command dev environment: **bash + zsh + fish** sharing one [Starship](https://starship.rs) prompt,
[Node](https://nodejs.org) via [mise](https://mise.jdx.dev), **Java via SDKMAN**,
[delta](https://github.com/dandavison/delta) git pager, and [opencode](https://opencode.ai) with
dynamic context pruning — on **CachyOS/Arch, Ubuntu, Debian and Fedora**.

## What's inside

| Area | Files | Notes |
|---|---|---|
| Shared shell env | `home/.config/shell/env.sh`, `aliases.sh` | Single source of truth: `PATH`, `EDITOR=micro`, `PNPM_HOME`, Podman `DOCKER_HOST` (socket-guarded), systemd `ssh-agent.socket` |
| Prompt | `home/.config/starship.toml` | Same prompt in all three shells; needs a Nerd Font |
| Bash / Zsh / Fish | `home/.bashrc`, `home/.zshrc`, `home/.config/fish/` | CachyOS base auto-detected; portable fallback elsewhere |
| Node toolchain | `home/.config/mise/config.toml` | node, pnpm, yarn + `github-cli`; `.nvmrc` compatible |
| Java | SDKMAN (installed by bootstrap) | `sdk install java 25.0.1-tem`; SDKMAN owns `JAVA_HOME` |
| Git | `home/.gitconfig`, `home/.config/git/ignore` | rebase+autostash, meld diff/merge, SSH commit signing, handy aliases |
| SSH | `home/.ssh/config` | Per-machine key generated by bootstrap; `allowed_signers` generated, never committed |
| Terminal / editor | `home/.config/alacritty/`, `home/.config/micro/` | MesloLGM Nerd Font, catppuccin-macchiato |
| opencode | `home/.config/opencode/` | `opencode.jsonc` (DCP plugin), `cli.json` (theme/diffs/session), `dcp.jsonc`, `package.json` |

> **Never committed:** `~/.ssh/id_*` private keys, `~/.ssh/allowed_signers`
> (per-machine, generated), `opencode/service.json` (contains a password),
> `node_modules`, lockfiles, `*.bak-*`.

## Quickstart

```bash
git clone https://github.com/<you>/dotfiles.git ~/code/dotfiles
cd ~/code/dotfiles
./bootstrap.sh -y
```

What it does, in order:

1. Detects the OS (`arch` / `debian` / `fedora` via `/etc/os-release`) and installs
   system packages from `packages/<os>.txt` (on Debian/Ubuntu it also normalises
   `batcat` → `bat`).
2. Installs **mise** (`~/.local/bin`), **starship** (`~/.local/bin`),
   **opencode** (official installer) and **SDKMAN** — skipped if present.
3. Installs **fisher + sdkman-for-fish** for fish users.
4. Symlinks every file under `home/` into `$HOME` (existing files are backed up
   to `*.bak-dotfiles-*`, or skipped without `-y`).
5. Installs mise tools (`mise install`: node/pnpm/yarn/gh), generates an
   ed25519 SSH key if missing, and writes `~/.ssh/allowed_signers` from it.

Useful flags: `--links-only` (just re-symlink after `git pull`),
`--no-packages` (skip the OS package manager).

### Fresh CachyOS reinstall

1. Install CachyOS, connect to network.
2. `sudo pacman -Syu git` (only prerequisite; everything else is scripted).
3. Clone + `./bootstrap.sh -y`, restart the terminal.

### Ubuntu / Debian cloud VM

```bash
# cloud-init user-data (runcmd) alternative:
#   runcmd:
#     - [su, ubuntu, -c, "git clone https://github.com/<you>/dotfiles.git ~/code/dotfiles && ~/code/dotfiles/bootstrap.sh -y"]
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/<you>/dotfiles.git ~/code/dotfiles
~/code/dotfiles/bootstrap.sh -y
```

Caveats on Debian/Ubuntu: `eza` only exists on Ubuntu 24.04+ / Debian 13+ —
aliases degrade gracefully to `ls` when missing; `gh` comes via mise (not apt).

### Fedora

```bash
sudo dnf install -y git
git clone https://github.com/<you>/dotfiles.git ~/code/dotfiles
~/code/dotfiles/bootstrap.sh -y
```

## After bootstrap (manual, ~5 min)

These need you, not the script:

1. **GitHub SSH**: Settings → SSH and GPG keys → add `~/.ssh/id_ed25519.pub`
   **twice** — once as *Authentication Key*, once as *Signing Key*.
2. `gh auth login` — browser flow; replaces the interim git credential cache.
3. **Java**: `sdk install java 25.0.1-tem && sdk default java 25.0.1-tem`.
4. **opencode**: `opencode auth login` per provider. Configs are already linked;
   plugins from `package.json` resolve on first run.

## opencode setup in detail

- Install (if bootstrap didn't): `curl -fsSL https://opencode.ai/install | bash`.
- This repo links `cli.json` (theme, word-wrap diffs, session UI),
  `opencode.jsonc` (loads `@tarquinen/opencode-dcp`), `dcp.jsonc` (DCP schema)
  and `package.json` (pins `@opencode-ai/plugin`).
- Auth state and `service.json` live only on the machine — run
  `opencode auth login` fresh per machine.

## Updating

```bash
cd ~/code/dotfiles && git pull && ./bootstrap.sh --links-only -y
```

## Customising

Edit files in `home/…`, commit, push, pull on the other machines and re-run
with `--links-only`. Machine-specific tweaks belong in non-committed drop-ins
(e.g. `~/.bashrc.local`, sourced if present — create it yourself) rather than
in the repo.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `mise: command not found` after bootstrap | `export PATH="$HOME/.local/bin:$PATH"` (or restart shell) |
| fish `sdk: command not found` | `fisher install reitzig/sdkman-for-fish@v2.1.0`, restart fish |
| `delta` pager errors on minimal Debian | `sudo apt install git-delta` or rely on mise fallback |
| Git commits "Unverified" | Signing key not yet added on GitHub (step 1 above) |
| `gh` not found | `mise install` (adds `~/.local/share/mise/shims` via shell hook) |
| Old `NVM_DIR` leaking into new shells | Close all terminals opened before the migration |

## Tested on

CachyOS (daily driver). Ubuntu/Debian/Fedora paths follow the same script but
are best-effort — please open an issue with the OS version and the failing step.
